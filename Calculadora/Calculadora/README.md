# Calculadora Web

Una calculadora simple hecha con HTML, CSS y JavaScript, servida con Node.js/Express.

## Estructura del Proyecto

```
.
├── package.json
├── .gitignore
└── calculadora_server/
    ├── package.json
    ├── app12.js         (Servidor Express)
    ├── index7.html      (Interfaz HTML)
    ├── script.js        (Lógica de la calculadora)
    └── style.css        (Estilos)
```

## Instalación y Uso

1. **Instalar dependencias del servidor:**
   ```bash
   cd calculadora_server
   npm install
   ```

2. **Ejecutar el servidor:**
   ```bash
   npm start
   ```

3. **Acceder a la calculadora:**
   - Abre tu navegador en: `http://localhost:3000`

## Requisitos

- Node.js v14 o superior
- npm o yarn

## Dependencias

- Express.js (para servir la aplicación)

---

Desarrollo local. Todos los archivos de `node_modules` y `package-lock.json` se generan al ejecutar `npm install`.
